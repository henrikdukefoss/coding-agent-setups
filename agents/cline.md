# Cline → any OpenAI-compatible endpoint

1. Open Cline's settings (gear icon) → **API Provider** → choose **OpenAI Compatible**.
2. **Base URL:** `https://your-endpoint.example.com/v1`
3. **API Key:** your key.
4. **Model ID:** the id your endpoint serves.

Works the same for local servers (`http://localhost:11434/v1` for Ollama).

Docs: https://docs.cline.bot/provider-config/openai-compatible
