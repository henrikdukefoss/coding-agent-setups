# Roo Code → any OpenAI-compatible endpoint

> The Roo Code extension was shut down on 2026-05-15 and its repository is archived. These steps are kept for existing installs; [Cline](cline.md) and [Kilo Code](kilo-code.md) have the same kind of OpenAI Compatible provider.

1. Open Roo Code settings → provider → **OpenAI Compatible**.
2. **Base URL:** `https://your-endpoint.example.com/v1`
3. **API Key:** your key.
4. **Model:** the id your endpoint serves.

Docs: https://docs.roocode.com/providers/openai-compatible
